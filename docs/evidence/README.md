# Evidence Pack

One folder per requirement ID from `../07-compliance-checklist.md`.

```
docs/evidence/
  GP-01/
    01-admin-creates-role.png
    02-role-restricts-menu.png
    notes.md
  GP-03/
    ...
```

`notes.md` carries anything a screenshot cannot show — file path and line reference for code-level
requirements (no hard-coding, no plaintext passwords), or a written statement for Phase 2 items.

This pack is a **payment gate** under the Garis Panduan, slides 3-5. Build it as you go.
